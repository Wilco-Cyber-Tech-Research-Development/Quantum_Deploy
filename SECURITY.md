# Security Policy

This repository is under active development. It does not currently publish a supported-version schedule, response-time commitment, or security-update service level.

## Reporting a vulnerability

Do not post exploit details, credentials, private data, or a proof of concept in a public issue.

If GitHub private vulnerability reporting is enabled for this repository, use **Security → Report a vulnerability** to send details privately. If that option is unavailable, use the maintainer’s GitHub profile to request a private reporting route without posting technical details publicly. No public email address is designated in this policy.

The project will acknowledge and assess reports when practicable. No fixed response timeline is promised.

## Scope

This policy covers only material maintained in this repository. Third-party packages and upstream code retain their own security policies and should also be reported to their upstream maintainers.
